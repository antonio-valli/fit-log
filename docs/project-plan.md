# FitLog – Project Plan

## 1. Project Overview

FitLog is a personal fitness tracking web application developed to help monitor weight, nutrition and daily workout activity through a centralised dashboard.

The application was developed as a personal software engineering project to strengthen my front-end development skills and gain practical experience with React, component-based architecture, application state and version control.

## 2. Project Objectives

The primary objectives are to:

- Record and monitor body weight against a target weight.
- Track daily calorie and protein intake.
- Record daily workout selections.
- Display key fitness information through a dashboard.
- Persist user information between sessions using browser Local Storage.
- Maintain a modular and maintainable codebase using reusable React components.

## 3. Target Users

**Primary target user:** Individuals who want a simple, personal way to monitor their fitness progress.

**Initial development user:** Myself, with the application initially designed around my own fitness tracking requirements.

## 4. Technology Stack

| Technology | Purpose |
|---|---|
| React | Building reusable user interface components |
| Vite | Development server and build tooling |
| JavaScript (ES6+) | Application logic and functionality |
| HTML5 | Application structure |
| CSS3 | Styling and responsive layouts |
| Local Storage API | Persisting application data in the browser |
| Git | Source code version control |
| GitHub | Repository hosting and project management |

## 5. Functional Scope

### Implemented functionality

- Fitness dashboard.
- Weight tracking and progress display.
- Daily calorie intake tracking.
- Daily protein intake tracking.
- Workout selection and tracking.
- Summary cards displaying key fitness information.
- Browser-based data persistence.

### Potential future functionality

- Historical weight and nutrition records.
- Visual weight progress charts.
- Exercise and workout history.
- Improved data management and validation.
- User authentication and cloud synchronisation.

## 6. Project Limitations

The current application is designed as a personal front-end project. It does not currently aim to provide:

- User authentication or account management.
- Cloud-based data storage.
- Social or community functionality.
- AI-powered recommendations.
- Integration with wearable fitness devices.

## 7. Development Approach

Development is organised into incremental improvements. Changes are managed through Git, with project documentation and source code maintained in the GitHub repository.

Future development will focus on improving maintainability, functionality, usability and the overall quality of the application.
